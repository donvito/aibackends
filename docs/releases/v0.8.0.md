# aibackends v0.8.0 — GLiNER2.5-Decide Classification

This release adds Fastino's GLiNER2.5-Decide checkpoints to the `gliner2.5`
extraction backend. Decide is tuned for operational classification — intent,
routing, sentiment, priority, policy, and multi-label tags — and scores several
classification heads in one forward pass, locally on CPU or GPU.

## Highlights

### Decide model variants

Two new named variants are available wherever `gliner2.5` accepts a `model`:

- `decide` — `fastino/GLiNER2.5-Decide` (340M, English)
- `multi-decide` — `fastino/GLiNER2.5-multi-Decide` (multilingual)

They load through the same `AutoExtractor` and classifier path as the existing
`small`, `base`, and `multi` variants, so model caching, batching, `_async`
variants, and CPU/CUDA/MPS device selection work unchanged.

### Richer classification tasks

```python
from aibackends.tasks import classify_text

result = classify_text(
    "Please reset the card PIN. The new one never arrived.",
    model="decide",
    tasks={
        "handoff": {
            "labels": ["yes", "no"],
            "prompt": "Should this be handed off to a human agent?",
        },
        "intent": {
            "labels": {
                "card_pin_change": "The customer wants a new PIN",
                "card_lost": "The physical card is missing",
            },
        },
        "rating": {"labels": [str(i) for i in range(11)], "ordinal": True},
    },
)
print(result.value("intent"))
```

`classify_text` and `classify_texts` task specs gain:

- `prompt` as an alias for `instruction`, and `cls_threshold` as an alias for
  `threshold`, so schemas from the Decide model card and notebook work as-is.
  Setting both an alias and its target raises `ValueError`.
- `ordinal: True` for ordered label scales such as ratings. It cannot be
  combined with `multi_label`.
- `{label: description}` label mappings. Descriptions are now passed through
  to the model — both in `tasks=` and the `labels=` shorthand — instead of
  being reduced to label names.

### Example

`examples/gliner25/decide_classification.py` is a runnable message router:
review sentiment and aspects, intent with label descriptions, an ordinal
rating, and a policy gate that blocks unsafe messages before routing the rest
to a human queue or an automated workflow.

```bash
python examples/gliner25/decide_classification.py --device cpu
```

## Known limitation

`fastino/GLiNER2.5-Decide-1B` is not a named variant. The checkpoint was saved
with transformers 5 (`tokenizer_class: TokenizersBackend`), while `gliner2`
requires `transformers<5`, so it cannot be loaded by any
`aibackends[extraction]` install. It will be added once the checkpoint or
`gliner2` is updated.
