# aibackends v0.8.1 — Clean JSON from GLiNER2.5 and GliGuard CLI tasks

This patch release fixes CLI output for the model-backed tasks that load
through `gliner2`.

## Fixed

`gliner2` prints a "Model Configuration" banner to stdout whenever it loads a
model. That banner ended up in front of the JSON emitted by the `gliner2.5`
and GliGuard CLI tasks, so piping them into tools like `jq` failed.

The `gliner2.5` and GliGuard backends now redirect that banner to stderr while
loading. Scripts still see it in the terminal, and these CLI tasks now emit
pure JSON on stdout:

- `classify-text`
- `extract-entities`
- `extract-graph`
- `moderate-prompt`
- `moderate-response`

```bash
aibackends task classify-text \
  --input "I was double charged, please refund one payment." \
  --labels refund_request,order_status \
  --model decide | jq '.tasks.label.labels'
```

No API changes. Upgrade with `pip install -U aibackends`.
